# Logistic Regression Pass or Fail

A beginner-friendly logistic regression example that predicts whether a student will pass based on study hours.

## What It Demonstrates

- Creating a small dataset with pandas
- Training a binary logistic regression model
- Predicting pass/fail for a new input value
- Printing a simple human-readable result

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate
pip install pandas scikit-learn
```

## Run

```bash
python LOGP1.PY
```

## Output

The script prints the raw model prediction and either `Student will Pass` or `Student will Fail`.



## GUI
Run the Streamlit interface with `streamlit run app.py`. The original `LOGP1.PY` console implementation is preserved.
